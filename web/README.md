# Microsoft Edge Update Page Replica

This directory contains a website that replicates the design of the Microsoft Edge browser update page.

## Features

- **Dark Theme**: Modern dark theme matching the Edge browser aesthetics
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **HTML5 Structure**: Semantic HTML5 markup
- **PHP Integration**: Server-side functionality for search features
- **CSS Animations**: Smooth transitions and hover effects

## Files

- `index.php` - Main page with HTML structure and PHP functionality
- `css/style.css` - All styling with dark theme
- `README.md` - This documentation file

## Key Components

1. **Header**: White checkmark icon in a circle with "Update complete!" message
2. **Navigation**: Next button for progression
3. **Features Section**: 6 numbered feature highlights
4. **Search Bar**: Functional search with PHP backend
5. **Footer**: Privacy links and copyright information

## Usage

1. Ensure PHP is installed on your server
2. Place files in your web directory
3. Access `index.php` through your web browser
4. The search functionality requires PHP to process form submissions

## Browser Compatibility

- Modern browsers with CSS Grid support
- Responsive design for mobile devices
- Progressive enhancement for older browsers
